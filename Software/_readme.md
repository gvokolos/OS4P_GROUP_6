# Software: RPM counting software from Daan v/d Putten. 
The hardware is also in the lab next to the rotating plate. Plug in the hardware, run the software on the IDE and you can get your results. 

Once you assemble the gearbox, you will need to test it according to the information you will find in the professors' readme file in the main directory, under the 'build instructions' chapter. We did not use this specific program because inside the large room of Lili's Proto Lab, next to the large disk you will use to experiment with the gearbox, you will find an Arduino board that you will connect to your computer and it is already set up. If it does not work, load this specific program.
